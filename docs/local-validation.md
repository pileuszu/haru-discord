# MLX 한국어 로컬 검증 — 2026-11-17 KST

> 최초 로컬 실험 당시의 기록입니다. 이후 Discord 전이중 연결이 추가됐습니다. 현재 실행 방법과 검증 범위는 [README](../README.md)와 [구조 안내](architecture.md)를 확인하세요.

## 결론

로컬 모델 실행과 한국어 음성·텍스트 출력에 성공했다. 두 번째 합성 음성 실험에서는 질문 순서에 맞춰 자기소개와 취미 응답을 생성했다. 이름 기억 질문에 대한 응답 텍스트는 나오지 않았으므로 안정적인 한국어 다중 턴 대화가 검증됐다고 판단하지 않는다. 사용자의 요청에 따라 자동 검증 결과까지 정리하며 Discord 연결은 진행하지 않았다.

## 실행 환경

- Mac mini Apple M4 / 통합 메모리 32GB
- 프로젝트 Python 3.12.15, MLX/MLX Metal 0.32.4
- Haru 코드: `7fe6b7665f8bf035998f401f8cb779fbe53f2751`
- Haru-4B 모델: `8d6e83bcd3701a76fc27a764965665da1df7da78`
- 언어 모델 backbone int8, 나머지 코덱·음성 헤드는 upstream 정밀도 유지
- 입력·출력 24kHz, 3,200샘플 프레임, seed 0
- 참조 목소리: 로컬 macOS Yuna 합성 음성. 실제 사람의 음성을 수집하지 않음

## 자동 실험

각 실험은 한 세션에서 아래 세 질문을 순서대로 입력했다. 질문 사이와 마지막 질문 뒤에 12초 무음을 넣었다.

1. 안녕, 나는 민수야. 만나서 반가워. 너는 이름이 뭐야?
2. 나는 주말에 공원에서 산책하는 걸 좋아해. 너는 쉬는 날에 뭐 해?
3. 아까 내가 이름을 말했는데, 내 이름이 뭐였는지 기억나?

| 항목 | 1차 | 2차 |
| --- | --- | --- |
| 입력 목소리 | Eddy 한국어 합성 | Yuna 한국어 합성 |
| 대화 길이 | 55.07초 | 50.00초 |
| 모델 로드 | 4.05초 | 3.78초 |
| 프리필 포함 계산시간 | 39.33초 | 32.48초 |
| 프레임 계산시간 p50 | 81.46ms | 83.77ms |
| 프레임 계산시간 p95 | 85.78ms | 87.38ms |
| MLX 메모리 최고치 | 6.72GiB | 6.82GiB |
| 한글 텍스트·유한한 비무음 출력 | 확인 | 확인 |
| 질문 대응 | 불명확 | 자기소개·취미 응답 확인 |
| 이름 기억 응답 | 미확인 | 마지막 질문 뒤 텍스트 없음 |

프레임 예산은 133.33ms이다. 두 실험의 p50/p95 계산시간은 예산 안에 들어왔다. 이 수치는 파일을 연속 처리한 **모델 계산시간**이며 마이크·네트워크·스피커를 포함한 왕복 지연이 아니다. 메모리 수치는 `mlx.core.get_peak_memory()`의 할당 메모리이고 프로세스 전체 RSS가 아니다.

## 2차 응답 및 시간 정렬

출력 텍스트: “아 안녕하세요. 아 저는 하루라고 해요. 스물네 살이에요. 저는 책 읽고 산책하는 거 좋아요.”

- 첫 질문 종료 5.386초 → 6.133초 인사, 8.267초 이름 소개.
- 두 번째 질문 종료 21.865초 → 23.467~24.533초 취미 응답.
- 마지막 질문 33.865~37.880초 → 50초 종료까지 새 텍스트 없음.

이름·나이·취미는 캐릭터 카드에 들어 있는 내용이므로 이 응답들만으로 입력 고유정보의 이해나 기억 능력을 입증하지 않는다. 모델 텍스트는 음성을 별도 ASR로 전사한 결과가 아니며 실제 발음 품질을 청취 평가하지 않았다. 무음 입력 대조군도 수행하지 않았다.

## 추가 확인한 사항

- `./scripts/haru setup` 재실행 성공, Metal GPU 인식.
- 공식 native macOS 앱 빌드 성공. upstream의 Swift raw-pointer 경고 1종이 있었지만 빌드는 완료됐다.
- 앱 실행 후 한국어 UI, 기본 한국어 참조 음성, “준비 완료” 상태 확인. 마이크 대화를 시작하지 않았다.
- 앱의 Python 래퍼가 프로젝트 캐시의 고정 체크포인트와 int8 기본값을 전달한다.
- `origin`: `https://github.com/pileuszu/haru-discord.git`. 이 로컬 검증 당시에는 원격 설정까지 완료했다.

다음 품질 검증은 실제 사람의 한국어 녹음 또는 직접 마이크 대화가 필요하다. Discord 연결 가능 여부와는 별개로 대화 응답의 안정성을 먼저 판단한다.
